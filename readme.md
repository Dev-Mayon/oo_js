# 🧠 Exercício de Programação Orientada a Objetos (POO) em JavaScript

Este repositório contém um exercício prático de POO utilizando **classes**, **herança**, **instanciação** e **abstração** com JavaScript moderno (`ES6+`).

---

## 📚 Descrição

### ✅ O que foi feito:
- Criação de uma **classe base abstrata**: `Animal`
- Criação de **duas classes herdeiras**:
  - `Cachorro`
  - `Gato`
- Instanciação de **três objetos** (duas instâncias de `Cachorro` e uma de `Gato`)
- Uso de métodos personalizados em cada classe

---

- JavaScript (ES6+)
- Git & GitHub
- VS Code
